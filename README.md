A stunning personal portfolio website showcasing **Prakash R**, a Senior Data Analytics professional with 12+ years of experience leading analytics teams and building data-driven solutions.

## Features

- **Hero Section** - Animated gradient background with key stats
- **About Me** - Professional bio with contact details
- **Skills** - Interactive skill cards organized by category
- **Experience** - Timeline-based professional history
- **Projects** - Featured projects with tech stacks
- **Download Resume** - Direct PDF and DOCX download
- **Contact Form** - Working contact form with validation
- **Responsive Design** - Fully mobile-friendly

## Tech Stack

- HTML5, CSS3, JavaScript
- Font Awesome icons
- Google Fonts (Inter)
- CSS Grid & Flexbox
- Smooth Scroll & Intersection Observer
